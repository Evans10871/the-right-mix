# The Right Mix

A Streamlit app for quickly finding opportunity and performance comparisons for Willow Creek Foods vs. the Remaining Market.

## Run locally

```bash
pip install -r requirements.txt
streamlit run the_right_mix_app.py
```

The app looks for `Fake Local Markets.xlsx` in the same folder by default. You can also upload another compatible workbook from the sidebar.

## Main views
- KPI summary for Willow Creek Foods vs. Remaining Market
- Opportunity Finder sorted by Opportunity Gap $
- Top opportunity chart
- Performance comparison scatterplot
- Market/category/subcategory filters
- Detailed comparison table

RM = Remaining Market.
